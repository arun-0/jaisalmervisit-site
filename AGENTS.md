# Jaisalmer Visit website

This repository serves jaisalmervisit.com from public/. The live app reads published visitor content from Firebase project visitjaisalmer-e3085. The shared human/AI project entry is `../business/dir-structure.md`; read it, `../business/TODO.md` and the newest `../business/WORKLOG.md` entry before substantive project work when that sibling checkout is available. Its AGENTS.md defines the shared record contract. Keep business status, approvals and the decision trail there; do not create a competing site TODO/dashboard. This repository's README remains the technical build/runtime/release reference. When the business checkout is absent, use the [shared entry](https://github.com/arun-0/jaisalmervisit-business/blob/main/dir-structure.md) through authorised access as needed; never fabricate current approvals.

Use Windows Git Bash. Run Python through uv and Node through fnm. Commit with the configured human identity. Keep tokens, transcripts, emulator data and private exports out of Git.

Use a topic branch for site changes. Verify the static build, the map and directory entry points, working links and the preview before publishing. Production hosting or DNS changes require explicit owner approval. Deploy only the static assets for a website release. Changes to Firebase rules, live records, billing, ads or social accounts are separate decisions.
